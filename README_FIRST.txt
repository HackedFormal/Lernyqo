LERNYQO — START HERE
=====================

Think of this file like the LEGO instruction sheet.
You do NOT need to understand the whole project before you start.

WHAT YOU NEED
-------------
1. A Windows PC.
2. Python 3.11 or newer.
3. Internet only if you want to use Live Gemini AI.

FIRST TIME
----------
1. Extract the Lernyqo folder somewhere easy, such as Desktop.
2. Open the folder.
3. Double-click START.bat.
4. A black window will appear. Do not close it.
5. Wait. The first setup installs the Python pieces Lernyqo needs.
6. Your browser should open Lernyqo.

EVERY NEXT TIME
---------------
1. Open the Lernyqo folder.
2. Double-click START.bat.
3. Keep the black window open while Lernyqo is running.

WHAT TO DO FIRST
----------------
1. Click Study Lab.
2. Click Try demo material, OR upload your own PDF/TXT/MD file.
3. Open the material workspace.
4. Try Understand → Key concepts → Flashcards → Quiz → Practice test.
5. If you get something wrong in a quiz, add it to the Mistake Notebook.
6. Add an exam in Exam Planner.

AI: THE EASY VERSION
--------------------
Lernyqo works without AI in Demo Mode. You can use the whole app for free.

If you want REAL AI from your own notes:
1. Open https://aistudio.google.com/apikey in your browser.
2. Create/copy a Gemini API key.
3. In the Lernyqo folder, find the file named .env.
4. Change:
       DEMO_MODE=true
   to:
       DEMO_MODE=false
5. Put your key after:
       GEMINI_API_KEY=
6. Save .env.
7. Start Lernyqo again with START.bat.

NEVER paste your API key into index.html or app.js.
Never send your .env file to anyone.

IF SOMETHING GOES WRONG
-----------------------
1. Do not delete random files.
2. Keep the black window open.
3. Read the error shown there.
4. Take a screenshot of the black window and send it to ChatGPT.

TO STOP LERNYQO
---------------
Close the black window, or press Ctrl+C inside it.
